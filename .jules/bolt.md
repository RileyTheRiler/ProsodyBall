## 2024-05-21 - Optimizing numerical array sorting in JS
**Learning:** In JavaScript, mapping an array of objects to extract numerical properties and then sorting them with `Array.prototype.sort((a,b) => a-b)` incurs overhead from intermediate array allocations and JavaScript callback invocations during sorting. Pre-allocating a typed array (like `Float64Array`), populating it via a standard `for` loop, and sorting it with the native `.sort()` method avoids these overheads and relies on native C++ sorting, which is significantly faster even for smaller arrays.
**Action:** Replace `pts.map(p => p.val).sort((a,b) => a-b)` with pre-allocated typed arrays and a standard `for` loop for population followed by `.sort()` when calculating statistics (like medians) on numerical properties derived from object arrays in hot paths.
